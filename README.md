# Decodificador de Texto

Projeto do Challenge ONE (Oracle Next Education + Alura). A página criptografa e descriptografa mensagens trocando as vogais por chaves:

| Letra | Vira |
|-------|------|
| e | enter |
| i | imes |
| a | ai |
| o | ober |
| u | ufat |

Exemplo: `gato` vira `gaitober`.

## Como funciona

- Aceita só letras minúsculas e sem acento (o site avisa se tiver algo diferente)
- Botões para criptografar, descriptografar e copiar o resultado
- Layout responsivo

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

Abra o `index.html` no navegador ou publique pelo GitHub Pages.
